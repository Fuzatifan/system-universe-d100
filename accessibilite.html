Déclaration d'accessibilité

Date de publication : 2 août 2026

Responsable : Yohann Poulain (Fuzatifan)

Engagement

Le site System Universe d100 est conçu avec l'accessibilité numérique comme priorité absolue. Notre objectif est de permettre à toute personne, quelle que soit sa situation de handicap, d'accéder à l'ensemble du contenu et des fonctionnalités proposés.

Ce site vise la conformité au niveau AA des Règles pour l'accessibilité des contenus Web (WCAG) 2.1.

État de conformité

Critère Niveau État Notes
Navigation 100% clavier A ✅ Conforme Tous les éléments interactifs sont accessibles au clavier. Raccourcis Alt+1 à Alt+4.
Attributs ARIA (live regions, roles) A ✅ Conforme Résultats de dés et tests annoncés via aria-live="polite".
Contrastes de couleurs AA ✅ Conforme (mode sombre) Ratio de contraste ≥ 4.5:1 pour le texte standard en mode sombre.
Mode clair / sombre AA ✅ Conforme Respect de prefers-color-scheme et bouton de bascule manuel.
Réduction des animations AA ✅ Conforme Respect de prefers-reduced-motion.
Textes alternatifs (images) A ✅ Conforme Toutes les images ont un attribut alt descriptif. Les icônes décoratives ont aria-hidden="true".
Synthèse vocale (Web Speech API) AAA ✅ Implémenté Les résultats de dés sont lus vocalement si la synthèse vocale est disponible dans le navigateur.
Documents PDF accessibles AA ⚠️ Partiel Des versions TXT accessibles sont fournies pour tous les PDFs. La conformité PDF/UA des PDFs n'a pas encore été vérifiée formellement.
Transcriptions des contenus audio A ⚠️ Partiel Les scripts des dramatiques audio sont disponibles dans le dépôt GitHub. Des transcriptions formelles sont en cours de publication.

Fonctionnalités d'accessibilité

Ce site intègre les fonctionnalités suivantes pour améliorer l'expérience des utilisateurs en situation de handicap :

  • Navigation entièrement au clavier avec raccourcis dédiés (Alt+1 à Alt+4, Espace).
  • Compatibilité avec les lecteurs d'écran NVDA, JAWS et le Narrateur Windows.
  • Annonces vocales des résultats de dés via la synthèse vocale du navigateur.
  • Régions ARIA live pour les mises à jour dynamiques de contenu.
  • Mode sombre (par défaut) et mode clair, avec respect de la préférence système.
  • Désactivation des animations si l'utilisateur le préfère (prefers-reduced-motion).
  • Versions texte pur (.txt) de tous les documents de jeu.
  • Lanceur de dés Python avec synthèse vocale française (pyttsx3).

Limitations connues

Malgré nos efforts, certains contenus présentent des limitations d'accessibilité que nous travaillons à corriger :

  • Les fichiers PDF n'ont pas encore été soumis à un audit de conformité PDF/UA. En attendant, des versions TXT accessibles sont disponibles pour chaque document.
  • Les fichiers audio des dramatiques (MP3) n'ont pas encore de transcriptions publiées sur le site. Les scripts sont disponibles dans le dépôt GitHub.

Contact

Si vous rencontrez des difficultés d'accessibilité sur ce site ou souhaitez signaler un problème, vous pouvez ouvrir une Issue sur GitHub.
